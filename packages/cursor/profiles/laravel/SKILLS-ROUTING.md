# Roteamento — complemento do projeto (Laravel)

Perfil: `laravel` (`npm run bootstrap -- <repo> --profile=laravel`).

Complementa `~/.cursor/SKILLS-ROUTING.md` — skills do projeto em `.cursor/skills/<nome>/` sobrescrevem o global.

## Stack

- PHP / Laravel — `composer.json`, `artisan`, `app/`, `routes/`

## Skills priorizadas

| Skill | Reforçar quando |
| --- | --- |
| `laravel` | Controllers, Eloquent, migrations, Blade, FormRequest, Jobs |
| `php` | Classes PHP fora do convenção Laravel |
| `testing` | PHPUnit, Pest, `tests/` |
| `security` | Input, auth, mass assignment |

## Rule do projeto

- `.cursor/rules/laravel-project.mdc` — editável e versionável neste repo
