# Templates — Cursor Automations

Rascunhos em linguagem simples para o Agent montar uma Automation no editor do Cursor (`/automations`).

Não são YAML oficiais da API — são **briefs** (nome, gatilho, instruções, ferramentas).  
**Não** instalamos review de PR nem pipeline CI neste monorepo.

| Arquivo | Uso |
| --- | --- |
| [nightly-sync.md](nightly-sync.md) | Lembrete / sync agendado do shared-ai |

Como usar: `/automations` no chat, ou copiar o brief e pedir “criar Cursor Automation com este draft”.
