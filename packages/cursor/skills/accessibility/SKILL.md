# Acessibilidade

## Quando usar

- Novos componentes interativos
- Auditoria WCAG ou teclado
- Correção de issues de leitor de tela

## Princípios

- HTML semântico primeiro; ARIA quando necessário
- Foco visível e ordem lógica
- Contraste e não depender só de cor
