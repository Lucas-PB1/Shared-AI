# TypeScript

## Quando usar

- Definir tipos de domínio e props
- Generics em utilitários
- Habilitar ou manter strict

## Princípios

- Tipos expressam contratos, não só anotações
- Evitar `any`; usar unknown na fronteira
- Narrowing antes de acessar propriedades
