# Mobile-first

## Quando usar

- CSS e layout responsivo
- Targets touch e gestos
- Priorizar conteúdo essencial

## Princípios

- Estilos base para viewport estreito
- Ampliar com min-width queries
- Funcionalidade core sem JS quando possível
