# Layout

## Flexbox

- Eixo principal e cross alinhados com `justify`/`align`
- `gap` em vez de margins hack entre filhos

## Grid

- Tracks explícitos ou `auto-fit`/`minmax` para responsivo
- Áreas nomeadas em layouts complexos

## Responsivo

- Mobile-first: base estreita, `min-width` media queries
- Container queries quando componente define breakpoint

## Evitar

- Alturas fixas que quebram conteúdo variável
- Posicionamento absoluto para fluxo principal
